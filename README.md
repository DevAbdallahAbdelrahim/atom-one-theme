# Atom One Theme for Obsidian

A clean, eye-friendly Atom One theme for Obsidian. Features dynamic &amp; responsive settings layouts, soft balanced contrast for extended writing, and full Light/Dark mode support.

A sleek, modern, and eye-friendly theme for [Obsidian](https://obsidian.md), inspired by the iconic Atom One syntax palette. Designed with a focus on visual balance, readability, and a fully responsive interface.

---

## ✨ Features

- **Dynamic & Responsive Settings Layout:** Settings panels automatically wrap and adjust gracefully across all window sizes and zoom levels without overlapping controls or text clipping.
- **Soft & Eye-Friendly Palette:** Replaced harsh neon accents with balanced, muted slate blues to reduce strain during late-night writing and research sessions.
- **Full Light & Dark Support:** Custom-tuned Atom One Light and Atom One Dark palettes with high-contrast text and code blocks.
- **Polished File Explorer & Syntax Highlighting:** Optimized sidebar hierarchy and crisp Markdown syntax styling.

## 🚀 Installation

### Manual Installation

1. Download `theme.css` and `manifest.json` from the latest release or repository root.
2. Open your Obsidian Vault folder and navigate to `.obsidian/themes/`.
3. Create a folder named `Atom One Theme` and paste both files inside.
4. In Obsidian, go to **Settings > Appearance > Themes**, and select **Atom One Theme**.
